Cette app connecte votre installation Niko Home Control 2 à Homey via la Hobby API locale et l'authentification JWT. Les appareils comme les lampes et les variateurs se commandent directement depuis les Flows Homey.

L'installation est simple : ajoutez votre unité de contrôle Niko Home Control 2, autorisez-la avec votre JWT et Homey détecte les appareils compatibles sur votre réseau. L'intégration fonctionne en local, pour une réponse plus rapide et un fonctionnement fiable.
