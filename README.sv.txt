Den här appen ansluter din Niko Home Control 2-installation till Homey via det lokala Hobby API:et och JWT-autentisering. Enheter som lampor och dimrar kan styras direkt från Homey Flows.

Installationen är enkel: lägg till din Niko Home Control 2-kontrollenhet, auktorisera med din JWT så hittar Homey kompatibla enheter i ditt nätverk. Integrationen fungerar lokalt för snabbare svar och pålitlig drift.
