Deze app verbindt je Niko Home Control 2-installatie met Homey via de lokale Hobby API en JWT-authenticatie. Apparaten zoals lampen en dimmers bedien je rechtstreeks vanuit Homey Flows.

De installatie is eenvoudig: voeg je Niko Home Control 2-controller toe, autoriseer met je JWT en Homey vindt de compatibele apparaten op je netwerk. De integratie werkt lokaal, voor een snellere reactie en een betrouwbare werking.
