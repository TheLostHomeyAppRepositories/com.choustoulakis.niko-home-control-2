Denne app forbinder din Niko Home Control 2-installation med Homey via den lokale Hobby API og JWT-godkendelse. Enheder som lys og lysdæmpere kan styres direkte fra Homey Flows.

Installationen er enkel: tilføj din Niko Home Control 2-controller, godkend med dit JWT, og Homey finder kompatible enheder på dit netværk. Integrationen fungerer lokalt for hurtigere respons og pålidelig drift.
